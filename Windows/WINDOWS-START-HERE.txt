TALLY 0.4.1 — WINDOWS

Install Tally-Setup-0.4.1-x64.exe on Windows 10/11 x64.

Double-click a .tally program. It opens a console and waits for Enter at the end.
Drawing commands open a separate native window. Close that window when done.
Use the Start menu's Tally Examples shortcut to find sample programs.
The Tally Editor shortcut opens an optional offline editor in your browser.

From a new terminal, after enabling the installer PATH option:
  tally program.tally
  tally program.tally --stats
  tally program.tally --svg drawing.svg

Code and drawing storage have no fixed quotas. Actual RAM, CPU and process stack
space determine what can run. Ctrl+C interrupts loops and waits.
For an optional instruction budget: tally program.tally --max-steps 1000000
The default is unlimited; --max-steps 0 also means unlimited.

Upgrading removes the old bundled Node.js runtime. Close running Tally programs
before installing. Student examples and unrelated files are preserved.
